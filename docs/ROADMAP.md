# ZShell 产品规划

本文记录做什么、为什么、先做哪个，以及尚未实现的功能的设计要点。功能实现后，跨模块的设计写进 [ARCHITECTURE.md](ARCHITECTURE.md)，模块内的细节写在代码注释里，并在下方里程碑表中标记 ✅。

## 定位

- 作为 Xshell 的替代，个人使用，macOS 与 Windows 体验一致。
- 优先补齐每天高频使用的操作（剪贴板、标签页、会话列表），再补 Xshell 的效率功能；不追求逐项对齐 Xshell。
- 行为尽量与 OpenSSH 一致（认证顺序、known_hosts、ssh_config 语义），减少"在 ZShell 里能连、命令行不能连"或反过来的情况。

## 现状（2026-10-08，M7 之后）

### 已具备

- SSH：密码 / 私钥 / agent / keyboard-interactive / 自动认证，known_hosts，密码存钥匙串，多跳 ProxyJump，keepalive 与带退避的自动重连。
- 终端：搜索、配色 / 字体 / 光标 / 回滚设置、本地终端（macOS 登录 shell、Windows PowerShell）；剪贴板快捷键、右键菜单、选中即复制、右键粘贴、多行粘贴确认、macOS Option 作为 Meta。
- 标签页：拖拽排序、重命名、复制（复用同一连接）、跟随远端标题、切换快捷键、关闭确认、右键菜单。
- SFTP：浏览、上传下载（进度、取消、拖入上传）、重命名 / 删除 / 新建 / chmod。
- ZMODEM：终端里的 rz / sz，SSH 与本地终端都可用，适合没有 SFTP 的堡垒机环境。
- 端口转发：`-L` / `-R` / `-D`，规则随会话保存、可自动启动，实时状态。
- ssh_config 导入、i18n 架构、macOS / Windows 发布流程。

### 相对 Xshell 的优势（保持）

- 一条连接复用：终端、SFTP、端口转发共用一条 SSH 连接，不像 Xshell + Xftp 那样各连一次、各认证一次。
- 原生支持 macOS（Xshell 没有 Mac 版）。
- ssh_config 导入、自动重连、转发规则实时状态、"自动"认证。

### 主要差距

| 方面 | 差距 | 优先级 |
|---|---|---|
| 会话管理 | 只有平铺列表：没有分组、搜索、快速连接、复制会话、右键菜单、导出导入 | P0 |
| 批量与效率 | 没有发送到所有会话（撰写栏）、快速命令、会话日志 | P1 |
| SFTP | 只能单选、只能下载到"下载"文件夹、不能拖出、不能用本地编辑器编辑远端文件 | P1 |
| 会话配置 | 没有 agent 转发、字符编码、单会话外观、登录后自动执行命令 | P1 |
| 布局 | 没有分屏 | P1 |
| 其他协议与杂项 | Telnet / 串口、X11 转发、出口代理、关键字高亮、主密码 | P2 |

### M8 会话管理

目标：管理几十到上百台主机时，能快速找到并打开会话。

- **分组**：文件夹可嵌套，拖拽调整会话和文件夹的位置；折叠状态记住。双击文件夹打开其中全部会话（Xshell 有此功能）。
- **搜索**：侧栏顶部搜索框，按名称、地址、用户名过滤；↑↓ 选择，Enter 连接。快捷键 ⌘K / Ctrl+K 聚焦。
- **快速连接**：在搜索框输入 `user@host[:port]`，没有匹配会话时提供"连接到 user@host"，使用"自动"认证；连接后可以一键另存为会话。
- **会话右键菜单**：连接、在新标签中连接、复制会话、编辑、删除、复制地址。
- **最近连接**：侧栏顶部可选显示最近连接的几个会话。
- **导出 / 导入**：导出为 JSON 文件（不含密码，钥匙串中的密码不导出），用于备份和多台机器同步；导入时按名称 / 地址识别重复。

### M9 标题栏集成

目标是两个平台外观一致，并省出一行高度：标签栏画进窗口标题栏区域（类似 Windows Terminal、VS Code）。排在 M6 之后，标签拖拽排序与窗口拖动区域可以一起验证。实现前另出详细设计。

- **不做自绘菜单栏**：macOS 的菜单栏是系统级的，应用无法去掉，且 WKWebView 的 ⌘C / ⌘V / ⌘A / ⌘Q 和 ⌘, 都依赖原生菜单，macOS 保留原生菜单栏；Windows 上的菜单项很少（新建本地终端、设置），不值得做一套菜单控件。Windows 也不启用原生菜单栏（传统 Win32 样式，深色模式支持有限）。
- **macOS**：`titleBarStyle: "Overlay"` 并隐藏标题，保留红绿灯按钮，标签栏左侧为其留出空间。
- **Windows**：`decorations: false`，自绘最小化 / 最大化 / 关闭按钮；保留窗口阴影与圆角。
- **拖动区域**：标签栏空白处用 `data-tauri-drag-region` 拖动窗口、双击最大化，与标签点击、关闭按钮以及标签拖拽排序互不干扰。
- **入口**：标签栏末尾的 "+" 打开本地终端，替代 M5 临时的侧栏标题栏按钮（macOS File 菜单中的 "New Local Terminal" 不再保留）。没有标签页时标签栏也要显示，保证入口始终可见。
- **风险**：Windows 11 悬停最大化按钮时的贴靠布局面板在自绘按钮上会丢失，需要额外处理（参考 decorum 插件的做法）；双击最大化、阴影、圆角、多显示器 DPI 都需在 Windows 上逐项验证（本地无法编译 Windows target，依赖 CI 与手动测试）；Windows 上现有的标题栏深浅色同步（`setTheme`）将不再需要。

### M10 批量与效率

- **发送到所有会话**（Xshell 的撰写栏）：标签栏下方可显示一个输入栏，输入的内容按 Enter 发送到选定范围：当前标签 / 所有标签 / 勾选的标签。另提供"键盘输入同步到所有标签"的开关，开启时标签栏有醒目提示，防止误操作。
- **快速命令**：命令按钮栏，命令可以是一段文本（可选是否自动回车）。按全局或会话分组保存，在终端右键菜单和命令面板中也能使用。
- **会话日志**：按会话设置是否自动记录，或在标签右键菜单中手动开始 / 停止。文件名模板（默认 `<会话名>_<日期时间>.log`），可选给每行加时间戳，可选去除 ANSI 控制序列。日志在后端写文件，不经过前端。

### M11 SFTP 增强

- 多选（⇧ / ⌘ / Ctrl 点选），批量下载、删除。
- 下载到指定位置（另存为），保留"下载到下载文件夹"作为默认动作。
- 拖出到 Finder / 资源管理器。
- 用本地编辑器打开远端文件：下载到临时目录，用系统默认程序或指定编辑器打开，检测到保存后自动上传（Xftp 中使用频率很高的功能）。
- 显示隐藏文件开关、列排序、按名称过滤。

### M12 会话配置

- **agent 转发**（`ForwardAgent`）：按会话开关；ssh_config 导入时一并映射。
- **字符编码**：按会话选择（默认 UTF-8，可选 GBK、GB18030、Big5 等），由后端在输出和输入两个方向转码，用于老服务器和网络设备。
- **单会话外观**：按会话覆盖配色（例如生产环境用红色背景）和字体，未设置时跟随全局设置。
- **登录后命令**：连接后自动发送的命令（如 `sudo -i`、`cd /srv/app`），按顺序执行。
- 会话级终端类型（`TERM`）与环境变量（SSH `env` 请求）。

### M13 分屏

- 标签页内左右 / 上下分屏，每个窗格是独立会话；分屏中的 SSH 窗格可以复用同一条连接。
- 拖动分隔条调整大小，快捷键在窗格间移动焦点。
- 与 M10 的"发送到所有会话"配合：范围增加"当前标签的所有窗格"。
- 需要把标签页模型从"一个标签一个会话"改为"一个标签一棵窗格树"，这也是排在 M10–M12 之后的原因。

### M14 翻译

语言设置界面，首批简体中文；做法见 [I18N.md](I18N.md)「新增一种语言」。

## 暂不排期（P2）

有实际需要时再排期：

- Telnet、串口（调试网络设备、嵌入式设备时需要）。
- X11 转发（macOS 上还要依赖 XQuartz）。
- 出口代理（SOCKS / HTTP）与 ProxyCommand。
- 关键字高亮（如 `ERROR` 标红）。
- 主密码 / 配置文件加密、锁屏。
- known_hosts 管理界面。

## 不做

- Xshell 的脚本（VBS / JScript / Python）：快速命令和登录后命令能覆盖大多数场景。
- 独立的密钥代理（Xagent）：使用系统的 ssh-agent / Pageant / Windows OpenSSH agent。
- 云同步服务：用导出文件配合用户自己的同步盘。
